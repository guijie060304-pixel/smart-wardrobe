# 产品需求（V2.0 摘要）

来源：用户引用的“优化AI开发提示词”聊天，2026-10-10 阅读。以本项目中后续明确的用户指令为准。

## 目标与边界

- Android/iOS 微信客户端上的智能电子衣橱。核心流程：上传衣服、分类管理、设置身材、2D 换装、保存穿搭。
- 原生小程序、TypeScript、WXML、WXSS、Canvas 2D；第一版本地存储，无独立服务器、账号、云同步、3D 或写实 AI 换装。
- 功能与稳定性优先，UI 初期简洁，后续单独优化。

## 衣橱

- 衣物新增、查看、修改、删除；搜索同时匹配衣物名称或具体品类名，分类、颜色、季节、风格继续作为附加筛选。同名不同衣物全部展示，分类为卫衣但自定义名称无“卫衣”时仍可按卫衣搜到。
- 必填图片与分类；名称、颜色、季节、风格、版型、材质、品牌、价格、购买日期、备注、标签选填。缺少名称时自动取分类名。ID 与时间由系统生成，普通页面不显示 ID。
- 分类配置统一维护，当前只用“大类→具体品类”两级：上装、下装、连体装、鞋履、配饰及其具体品类。用户明确暂不需要第三级；版型、长度、腰型优先用属性或标签表达。
- 支持拍照/相册、预览、基础裁剪、方向调整、重选。图片存为持久本地文件；记录展示照片和可选透明贴图，处理取消、权限、损坏、容量与文件丢失。

## 人体与试衣

- 明确男/女陈列模特，身高 150–200 cm；记录体重、胸围、腰围、臀围；选填肩宽、上身长、内侧腿长和女模下胸围。表单提供测量提示与即时预览，参数驱动本地曲线/明暗模型，仍不代表精确三维体型。
- 用户后续明确：体重及胸腰臀只校验有限且大于零，暂不设上限；原始数据不能因绘制适配而改变。
- 原始身材、逻辑坐标和画布坐标分离；按画布宽高取统一最小缩放，居中、完整显示、按像素比绘制，尺寸变化后重绘。
- 第一版优先试穿 T恤、衬衫、卫衣、外套、裤子、半身裙、连衣裙。普通背景照片可入衣橱，但试衣贴合效果不保证；允许透明 PNG 贴图。
- 可选择、替换、移除衣物，组合上装/下装/外套，处理连衣裙互斥，清空并保存。衣物与人体使用同一逻辑变换；贴图可平移、等比缩放、旋转和重置。图层由独立规则管理。

## 穿搭与页面

- 穿搭保存衣物 ID、图层、调整参数、可选画布排列/叠放顺序、名称、时间；可创建、查看、编辑、删除、恢复。按最新要求自由搭配名称选填，留空/纯空白自动生成日期名称，填入则使用自定义名；模特试衣保留命名。删除被引用衣物时需处理关联关系。
- 用户确认：删除衣物后保留穿搭并标记衣物缺失，仍可查看、载入并替换；不能静默删除穿搭中的原位置。
- 四个底部入口：首页、衣橱、试衣、我的；首页突出“开始自由搭配”，衣橱顶部以“衣物管理 / 自由搭配”切换，“我的穿搭”顶部可新建自由搭配。自由搭配直接选衣保存，可先排列画布；模特试衣用于人体预览，两个草稿独立。
- 2026-10-13 用户追加：穿搭详情默认无模特画布，可拖动排列、缩放/旋转、保存后重开保留，显式切换查看模特。画布/模特参数分开。用户明确确认长按拖动“覆盖”为置顶叠放，不替换被覆盖衣物；单指普通滑动仍滚屏。活动穿搭卡片提供直接删除，确认后进入回收站，不改衣橱和日历。
- 首页提供统计、快捷入口、最近内容和空状态。衣橱双列卡片与筛选；详情可编辑、删除、加入穿搭。试衣页上方画布、下方衣物面板和调整工具。我的页含身材与本地数据入口。
- 竖屏与安全区域适配，空状态、加载、输入错误和图片错误均有反馈；删除二次确认。

## 验收原则

- 2026-10-13 新增穿搭日历：上方月历可切月/选日/回到今天，下方同一天可加入多套已保存穿搭，作为当天参考与日后回顾；可添加、编辑、清空当天注意事项，月历区分有穿搭/有备注。每日最多 12 套、备注最多 1000 字。加入时在本机保留当时名称、衣物信息与照片副本；来源改名/删图不改历史存档。入口放在首页和我的穿搭；未保存备注切日期/离开时保护输入。没有系统通知、云同步或 AI 调用。

- 每阶段运行相关测试并如实记录；最终需验证微信开发者工具、Android、iOS、不同屏幕和像素比。没有实际设备时保持待验证。

## 已批准的本地贴合扩展（2026-10-13）

用户同意不用 AI 的 2D 分区变形：透明正面平铺图可规则估算衣身/袖子或裤身/双腿，支持余量、袖长和穿着长度。详情/试衣提供一次校准并保存复用，换有效图片/品类需重做；可关闭并保留原图。不上云，不调用 AI，不自动去背景，不作真实尺码/物理布料承诺；连体裤/背带裤沿用原图。

## 已批准的白模扩展（2026-10-13）

根据用户男女白模截图，采用本地立体白模固定正面显示并保留 2D 贴衣/校准。男女发型、白色材质、基础衣裤和浅色台座；基础衣裤按真实图层替换，不作为用户衣物。参数仍驱动人体，不上传，不作 360° 全 3D 衣物或真实个人建模承诺。
