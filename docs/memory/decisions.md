# 决策

## 2026-10-14 · 本地辅助抠图

- 用户在规划中选择“本地辅助”“平铺/悬挂单件”“框选生成初稿”“衣橱和搭配统一使用”，随后明确要求实施。允许本地颜色/边缘估算，未授权云服务或 AI 模型；本次替代历史的“尚不提供抠图”范围约束。
- 统一透明 PNG，衣橱衬白底，编辑器可切白底/棋盘格，不烘焙白色方框。手动圈选及保留/擦除用于同色背景、衣架和复杂边缘，不补画被遮挡衣物。
- 保留抠图前原照片；“使用结果”只是表单草稿，显式保存后生效。已有独立试衣贴图在应用抠图时被统一结果替换；恢复原图清除当前贴图。日历历史副本保持原样，保存失败不破坏旧图。
- 复用原生 Canvas，不加入运行时第三方库、Worker 打包链或模型文件。分析 256、输出 1024、十步撤销和十秒估算期限控制首版资源消耗，手机性能仍需实测。

- 用户明确确认“长按图片覆盖另一张”为拖动叠放到上层，不是替换或删除另一件。画布和模特试衣长按均置顶，普通单指仍优先滚屏；详情提供置顶/置底按钮以找回被遮住的衣物。
- 活动穿搭卡片直接删除，确认后进入既有回收站，误删可恢复；衣橱和独立日期存档保留。不引入上传、AI、云服务或运行依赖。

## 2026-10-13 · 穿搭日历

- 用户明确要求日历上选日期、下方保存几套穿搭用于参考/回忆、添加注意事项。沿用原生小程序和本地保存；新增业务模块，不引入系统通知、AI、云服务或新的运行依赖。
- 日期存档是普通穿搭引用之外的独立快照：复制当时名称、衣物信息与本地照片。来源以后改名/换图/删除不会改旧存档；这会额外占用本机图片空间，移除日期穿搭时清理专属副本。每个日期最多 12 套、备注 1000 字，备注可独立保存。
- 显式保存注意事项，未保存切日/离开保护输入；逐日 revision 防止过期覆盖。月历使用纯日期计算，不把 UTC ISO 日期当成本地今天。入口放首页和“我的穿搭”，普通衣橱/试衣草稿不参与日历写入。

## 2026-10-12 · 试衣交互

- 根据用户要求移除下方缩放/旋转滑块和四向按钮，调整直接发生在画布：轻点选中、长按拖动、双指缩放/旋转；画布旁保留重置/移除。普通单指滑动优先交给原生页面滚动，滚动开始后不切换为衣物调整。
- 双指按触点身份匹配并以两指中点变换，达到比例边界后可立即反向；部分手指松开后暂停调整直到全部松开，避免跳变。重叠时轻点选顶层；长按/双指优先调整命中区域内已选衣物，列表可先选择内搭。
- 只有试衣页开启可交互预览，详情保持只读。命中基于实际绘制的图像矩形，暂不分析透明像素。

## 2026-10-13 · 不用 AI 的分区贴合

- 用户同意本地 2D 网格方案；不引入推理服务、3D/物理依赖或上传。此决定扩展历史“始终等比贴图”实现：原图模式保留，支持品类可分区变形。
- 每件衣物校准一次并复用，而非每次试穿重新拖裁。原图归一化点绑定有效展示/贴图路径和 typeId，换有效图片或品类失效，穿搭仍仅存衣物引用。
- 自动初值仅针对透明非矩形剪影；规则估算允许修正，不将矩形照片透明外边框误判成可用剪影。普通背景不会去除，用户可手动校准但会提示背景随图变形。
- 上装/外套、裤装、半裙、连衣裙支持；连体裤/背带裤维持原图。坏点/翻折安全回退；“保留原图”可显式关闭。仅局部手颈前景和示意明暗，不宣称真实尺码或面料模拟。
