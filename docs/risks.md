# 技术风险与处理计划

- **本地图片持久化**：临时路径不可当长期地址；第二阶段保存到用户文件目录，并测试取消、容量不足、文件丢失和删除清理。
- **分类范围**：用户已确认当前只需“大类→具体品类”两级。若以后增加第三级，需要先迁移分类模型与已有数据。
- **试衣素材质量**：普通背景照片会遮挡人体；透明贴图已支持，不自动抠图。透明外围边距现已在支持离屏像素读取时排除，模拟器合成素材检查通过；读取失败回退原图。已加入袖子/衣身/裤腿分区和局部手颈前景，但规则点需要校准，真实素材待验证；透视/物理布料未模拟。复杂垂袖、褶皱、非正面图与背景不保证适配，不能承诺任意照片自然贴身。
- **人体示意与适配**：胸腰臀等数据不足以准确还原体型；第三阶段自动化和浏览器 Canvas 检查通过，阶段六又在微信模拟器中看到两种完整人体。更多屏幕尺寸与真机表现仍待验证。
- **开发者工具验证**：本机 CLI 服务端口已开启，模拟器完成部分衣物、身材、Canvas 和穿搭交互。相机/相册、裁剪、触摸拖动与 Android/iOS 真机仍待验证，见 `docs/acceptance-checklist.md`。
- **穿搭引用**：用户确认保留缺失引用，已实现标记、原样载入与主动替换/移除；回收站恢复不恢复衣物。预览使用最新照片及当前身材，不能还原过去图片或身材。
- **试衣会话**：已保存穿搭可重新载入；未保存草稿仍只驻留内存，运行结束后不保证恢复。已保存穿搭的失效位置保留，新草稿失效衣物会移除。
- **穿搭存储**：损坏数据拒绝覆盖、保存失败保护草稿及版本冲突已有测试；设备实际存储失败和导航返回仍需微信验证。回收站记录持续占本地空间，暂未提供永久清理入口。
- **异步与触摸**：迟到图片、卸载后更新、坐标换算和跨页流程已通过模拟事件测试；滑块已移除，真实微信中的长按/双指/原生滚屏、渐变绘制性能、内存占用及快速换衣性能仍待验证。

- **立体白模开销**：运行时三维软件光栅化在模拟器超时，已改为开发时生成两张本地 PNG（约 165 KiB）再按身材适配，连续手势复用纹理，图集单独缓存。离屏失败直接绘制，资源缺失回退曲线；手机首次解码、内存和极端身材的投影失真仍需验收。人物固定正面、衣物保持 2D，不宣称 360° 包裹或物理贴合。
