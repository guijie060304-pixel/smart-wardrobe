# Smart Wardrobe 智能电子衣橱

原生微信小程序项目，按 `docs/development-plan.md` 分阶段开发。

## 开发

1. 安装 Node.js，运行 `npm install`。
2. 运行 `npm run typecheck` 进行静态类型检查，`npm test` 运行衣橱、人体、试衣与穿搭逻辑/事件测试。
3. 用微信开发者工具导入本目录；小程序根目录是 `miniprogram/`。现有 `project.config.json` 中的 AppID 保持原值。

当前已实现衣物管理、身材设置、2D 试衣和穿搭保存管理。首页点“开始自由搭配”，或切换衣橱顶部“自由搭配”，选中上装/下装等衣物后直接保存。搭配名字选填，留空自动生成日期名称；填入则使用自定义名，最多 60 字。“我的穿搭”顶部也有“新建自由搭配”入口。自由搭配无需设置身材，与模特试衣分别保留草稿；保存后留在搭配模式，可继续选下一套。

选衣后可点“排列画布”；已保存穿搭打开时默认也是画布。轻点选中、长按拖动并置顶、双指缩放/旋转，允许叠放；详情点“保存排列”后重开保持。画布排列与模特试衣位置分别保存，可显式切换模特预览。已保存卡片可直接确认删除到回收站，再从回收站恢复；删除不改衣橱和日历。删除衣物会保留穿搭中的缺失位置。试衣页“开始新一套 · 重新选衣”会重置试衣草稿和筛选、定位到选衣区域并提示，未保存修改需确认。

阶段 7 第一版视觉样式已完成，使用暖纸白、深松绿和陶土色；设计选择见 `docs/visual-design.md`。

类型检查、131 项自动化测试及开发者工具 CLI 编译通过；模拟器已验证本地抠图实际 PNG 导出/保存重开/原图恢复，以及直接保存、默认画布、排列保存重开与卡片删除，改动页面亦通过 WXML/WXSS 独立编译。模拟器手势通过页面/组件方法注入，部分确认结果临时模拟；真实照片、实际相机/相册、原生手势与滚屏、更多屏幕尺寸和 Android/iOS 真机仍需验收。未保存草稿只在当前运行中保留。进度见 `docs/progress.md`，逐项结果见 `docs/acceptance-checklist.md`。

添加或编辑衣物，选图后点“去背景”：框住完整衣物生成初稿，再用保留/擦除笔修边，或手动圈出轮廓；支持双指缩放/移动、粗细调整、十步撤销、白底/透明底预览。点“使用结果”回到表单，再保存衣物后，衣橱与搭配统一使用透明 PNG；原照片保留，可重新抠图或恢复。处理完全在本机，分析最长边 256、编辑/导出最长边 1024，初稿估算超过十秒可改用手动圈选。相近颜色、衣架和阴影可能需要修边，不补画遮挡部分。

首页或“我的穿搭”点“穿搭日历”：上方月历切月/选日，下方给当天加入多套已保存穿搭，并记录注意事项。每天最多 12 套、备注最多 1000 字；有记录的日期显示标记。加入时保留当时名称与本地照片副本，方便之后回顾；移除仅影响当天存档。注意事项显式保存，未保存切换日期会提示。所有数据和照片仍在本机，不提供系统通知或云同步。

衣物详情点“校准衣物贴合”，或在试衣间选中衣物后点校准入口，可标记肩/腋/袖口或裤裆等，预览后保存一次，后续自动按当前模特复用。可选择贴身/常规/宽松、袖长/长度，也可保留原图。上装/外套、裤装、半裙和连衣裙支持分区贴合；连体裤/背带裤仍用原图。推荐透明、正面、袖子展开的平铺图，背景杂乱可先用本地辅助抠图；不模拟真实布料或判断尺码。计算与记录均在本机，不调用 AI。真实素材和手机体验仍待验收。

模特已按参考风格改为三维预渲染白模的固定正面画面，图集随程序内置并在本机按身材适配，包含男女发型、雕塑式面部与手足细节、光照和浅台座。空模特显示基础白色衣裤，选入衣物后对应替换；它们不加入衣橱或保存穿搭。已保存校准继续使用，衣物仍是 2D，不提供整套转身；无需 AI 或远程算力。
